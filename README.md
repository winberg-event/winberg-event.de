# winberg-event.de

Entwicklungsrepository für die Website von **WINBERG Event & Consulting**.

## Entwicklungsstand

Die aktuelle Gestaltung liegt im Branch `site-v1` und ist noch **nicht für Suchmaschinen oder die produktive Domain freigegeben**.

Technische Leitlinien:

- statische, schnelle Website für GitHub Pages
- echte HTML-Typografie und Formularelemente statt Screenshot-Website
- skalierbare SVG-Landschaften und Ornamente für scharfe Darstellung
- feste Desktop-Navigation links, mobile Off-Canvas-Navigation
- keine externen Webfonts
- keine Tracking-Skripte im Entwicklungsstand
- rechtliche Seiten sind derzeit nur Platzhalter
- Kontaktformular versendet im Entwicklungsstand noch keine Daten
